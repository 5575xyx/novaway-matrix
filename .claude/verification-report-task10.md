## 问题

### 重要问题

#### 1. DOM选择器语法问题
**文件**: `packages/opencode/src/skill/prompt/wxgzh-ops/references/selectors-reference.md:49-51`

```javascript
const saveButtonSelectors = [
  '#js_submit',
  'button:contains("保存为草稿")',
  // ...
];
```

**:contains** 不是标准的CSS选择器，需要使用JavaScript的`textContent`属性来匹配。这可能导致在实际运行时无法正确找到按钮。

**建议修复**:
```javascript
const saveButtonSelectors = [
  '#js_submit',
  // 使用JavaScript匹配textContent
];
```
