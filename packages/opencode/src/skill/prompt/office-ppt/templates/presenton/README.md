# Presenton 模板库

本目录包含从 Presenton 提取的 7 个 Apache-2.0 模板家族。模板以 1280×720 的结构化 JSON 保存，共 134 个布局，并保留原项目的缩略图、装饰图片、SVG 与字体资源。

## 使用方式

1. 先读取 `catalog.json`，根据模板 ID、布局描述、文字槽位容量、配色和字体筛选候选布局。
2. 只在需要精确复刻时读取对应 `<模板>/template.json`，不要把全部 7 份大文件同时载入上下文。
3. 页面 HTML 必须使用 1280×720 `.wrapper` 画布，并将模板的坐标、留白、层级和字体气质转译为可编辑 DOM 元素。
4. `static/` 中的资源使用相对路径；远程占位图必须在导出前替换为工作区本地文件。
5. 每页生成后执行截图审查，再由 `opencode office-ppt` 导出为可编辑 PPTX。

## 模板家族

| ID          | 布局数 | 推荐场景                       | 视觉特征                     |
| ----------- | -----: | ------------------------------ | ---------------------------- |
| `dynamic`   |     32 | 产品发布、营销提案、增长方案   | 高对比橙黑、强图片、动态构图 |
| `editorial` |     24 | 品牌故事、内容报告、创意案例   | 衬线标题、图文杂志式叙事     |
| `executive` |     32 | 高管汇报、战略评审、董事会材料 | 紫黑、超大标题、强结论页     |
| `general`   |     12 | 通用商务、项目汇报、方案沟通   | 紫灰、卡片化、信息层级稳定   |
| `modern`    |     10 | 融资路演、产品介绍、创新方案   | 蓝白、充足留白、现代无衬线   |
| `momentum`  |     28 | 业务复盘、团队动员、里程碑汇报 | 黑白蓝、粗体标题、强节奏     |
| `standard`  |     11 | 正式报告、咨询交付、品牌叙事   | 绿白、衬线标题、克制专业     |
| `swift`     |      9 | 快速提案、轻量路演、创意简报   | 浅蓝黑、简洁几何、轻快节奏   |
