# 数据库连接与使用规则（内置全局规则）

## 已保存的数据库连接自动注入
AI 的系统提示中已自动注入所有在 UI Database Tab 中保存的数据库连接信息。
如果提示中有连接信息，AI 应直接使用其中的参数，无需询问用户。

如果没有已保存的连接（系统提示中无连接信息），AI 应询问用户输入连接参数。

## 如何操作数据库（优先使用内置工具）

你有一个内置的 `database_sql` 工具，可以直接执行 SQL 语句。
优先使用 `database_sql` 工具，而不是用 shell 工具手动调用数据库 CLI。

### 使用方式
1. 使用 `database_sql` 工具，传入连接参数和 SQL 即可
2. 如果系统提示中有已保存的连接，优先使用其中的参数
3. 连接参数包括：type（数据库类型）、host、port、user、password、database、sql
4. 支持类型：mysql、postgresql、sqlite、sqlserver、mariadb

## DDL 与初始化
- 创建表使用 `CREATE TABLE IF NOT EXISTS` 避免重复执行
- 插入测试数据使用 INSERT 语句
- DDL 和数据插入的结果应在 Database Tab 和对话中都可查看

## 错误处理
- 如果 CLI 工具未安装，提示用户安装对应数据库客户端
- 如果连接失败，检查 host/port/credentials 是否正确
- 如果是 SQL 语法错误，修正后重试
- 如果 `database_sql` 工具不可用，回退到使用 shell 工具手动调用 CLI
