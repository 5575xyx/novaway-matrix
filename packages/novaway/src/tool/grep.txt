Fast content search across the codebase using ripgrep.

Usage:
- Searches file contents with full regex syntax (eg. "log.*Error", "function\s+\w+").
- Narrow with `include` (glob, eg. "*.ts") or `type` (ripgrep file type, eg. "ts", "py").
- `output_mode`:
  - "files_with_matches" (default): list of file paths. Cheapest; use when you only need to know where.
  - "content": matching lines grouped by file. Supports -A/-B/-C context lines and -n line numbers.
  - "count": match count per file.
- `head_limit` defaults to 250 entries; pass 0 for unlimited. Use `offset` to page through results.
- `multiline: true` lets a pattern span lines (use [\s\S]*? between anchors).
- Results are ordered by file modification time (newest first).
- Prefer this over reading whole files when you know what symbol or string you are looking for.
