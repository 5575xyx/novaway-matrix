# AI 写作特征清单（中文）

按「一眼就能认出来」排序。改写时逐条对照，命中就改。

## 1. 空话开场 / 收尾

- 开场：在这个快节奏的时代 / 随着…的发展 / 不知道你有没有发现 / 今天想和大家聊聊
- 收尾：综上所述 / 总而言之 / 希望这篇文章对你有帮助 / 让我们一起…
- 改法：开场直接给场景、结论或冲突；收尾给一个具体动作或真问题。

## 2. 模板化结构

- 「首先…其次…最后…」「第一…第二…第三…」用在 300 字以内的小文里。
- 每段都是「观点 + 解释 + 举例」三个完整成分，节奏完全一样。
- 改法：长短句混着来，允许一句话成段；不必每个观点都配例子。

## 3. 排比与对仗

- 「不仅是…更是…」「既…又…」「让…更…，让…更…」
- 三个以上结构相同的短语连续出现。
- 改法：留一个最强的，其余删掉或改成不同句式。

## 4. 翻译腔

- 「一个…的事实是」「值得注意的是」「在很大程度上」「基于…的考虑」
- 被动句过多：「被认为」「被广泛使用」。
- 改法：换成主动句和口语：「其实」「要注意的是」「因为…」。

## 5. 抽象名词与黑话

- 赋能、闭环、抓手、心智、链路、颗粒度、组合拳、护城河、飞轮。
- 改法：直接说做了什么、谁受益、结果怎样。

## 6. 没有具体信息

- 通篇没有数字、时间、地点、品牌、价格、人名、具体动作。
- 形容词堆叠：「非常优秀」「极其重要」「显著提升」。
- 改法：换成一个可核验的事实；核验不了就删。

## 7. 过度完整

- 每个论点都「优点 + 缺点 + 建议」，像报告而不是分享。
- 改法：只讲最有用的那一个点，其余一句带过或直接不写。

## 8. 标点与格式

- 频繁使用破折号补充说明、括号里再补充。
- emoji 每句一个，或完全不用（真人通常是不均匀的）。
- 改法：按平台习惯来，小红书可以适度，公众号基本不用。

## 快速自检

把改完的稿子读一遍，问四个问题：

1. 有没有一句话删掉之后意思不变？（有 → 删）
2. 有没有一个具体的细节？（没有 → 补或删这段）
3. 句子长度是否一样长？（一样 → 拆/合）
4. 这像是这个人会说的话吗？（不像 → 重写开头）
