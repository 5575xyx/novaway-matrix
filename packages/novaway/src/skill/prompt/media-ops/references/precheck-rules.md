# 发布前预检规则

这份清单与 `packages/desktop/src/main/platform/publish/precheck.ts` 一一对应。
发布中心会自动跑一遍；在聊天里直接写稿时，你（模型）要按这份清单自己过。

分级：**error 必须改**（平台一定发不出去）；**warning 建议改**（大概率限流/驳回）；**hint 提醒**。

## error：一定发不出去

| 规则 | 判据 | 改法 |
| --- | --- | --- |
| content-empty | 标题和正文都为空 | 至少写一段正文 |
| files-missing | 视频/图文没有选素材 | 先选素材 |
| video-multiple | 视频发布给了多个文件 | 只留一个 |
| wechat-title-required | 公众号文章没有标题 | 补标题 |

## warning：大概率限流 / 被驳回

### 长度（按平台分别算，单位是码点，emoji 算 1 个字）

| 平台 | 标题上限 | 正文上限 |
| --- | --- | --- |
| 公众号 | 64 | 20000 |
| 小红书 | 20 | 1000 |
| 抖音 | 55 | 1000 |
| 视频号 | 30 | 1000 |
| 快手 | 30 | 500 |
| B站 | 80 | 2000 |

标题超过 30 字另有一条通用提醒：信息流只露前 20 字，钩子等于白写。

### 极限词（《广告法》第九条高频子集）

- 最好 / 最佳 / 最优 / 最强 / 最低 / 最高 / 最大 / 最先进 / 最专业 / 最权威 / 最便宜 / 最划算 / 最受欢迎 / 最值得
- 全国第一 / 全球第一 / 世界第一 / 行业第一 / 销量第一 / 排名第一 / 口碑第一
- 第一名 / 第一品牌 / 首选品牌 / 领导品牌 / 销量冠军
- 顶级 / 顶尖 / 极致 / 唯一 / 独家 / 首创 / 史无前例 / 万能 / 绝对 / 永久有效 / 百分百 / 100%有效
- 国家级 / 世界级 / 全球首发 / 国家免检 / 国家认证

改法：换成可核验的具体事实（「比同类少 30%」「连续 6 个月复购第一（来源：XX 报告）」），或直接删掉。

**不要误伤**：「最近」「最后」「最后一步」不是极限词；「第一次用」也不是排名。

### 站外引流

- 微信号 / 加微信 / 加V / vx / V信 / 威信 / 薇信
- 扫码 / 二维码 / 进群 / 群聊 / 私信我 / 私信领取 / 扣1 / 扣一 / 链接在简介 / 主页有链接 / 看我主页

改法：把用户留在平台内（收藏、关注、评论关键词），或使用平台官方的引流组件。

### 功效与收益承诺

- 医疗：治愈 / 根治 / 包治 / 药到病除 / 一贴见效 / 无副作用 / 永久脱毛 / 包瘦 / 立刻见效
- 收益：稳赚 / 保本 / 零风险 / 躺赚 / 暴富 / 日入过万 / 月入十万 / 翻倍收益 / 无风险套利

改法：改成体验描述（「我用了三周，感觉…」），不承诺结果；金融类内容需要资质。

### 标签

- 重复标签 → 去重；
- 超过 10 个 → 平台通常只认前几个，保留 3-6 个；
- 单个超过 20 字 → 缩短。

### 定时

- 定时时间已经过去 → 改成将来的时间，或直接发。

## hint：提醒，不拦

- 抖音 / 小红书 / 视频号要求标注 **AI 生成**：发布页有开关就打开。
- 文章类内容带了视频/图片素材：这些素材不会被使用。

## 输出格式

发现问题时，按「哪句 → 违反了哪条 → 怎么改」三段给，不要只说「有风险」。
一次最多列 8 条，按 error → warning → hint 排序。
