# 数据库使用规则（内置全局规则）

## 用内置数据库工具，不要走 shell CLI

访问数据库一律用下面 4 个工具。连接由用户在「数据库」页面维护，和这里看到的是同一份。

- `database_list`：列出已保存的连接（id、类型、地址、是否存了密码）
- `database_tables`：列出某个连接下的表 / 视图
- `database_describe`：查看单张表的列（类型、可空、默认值、主键）
- `database_query`：执行 SQL

## 使用顺序

1. `database_list` 拿到 connectionID（也可以传连接名）。
2. 不确定结构就 `database_tables` → `database_describe`，别凭猜测写列名。
3. `database_query` 执行；SELECT 会被自动分页（默认 100 行，可用 limit/offset）。

## 写操作

- 默认**只读**：INSERT / UPDATE / DELETE / DDL 会被直接拒绝。
- 确实要写时传 `allowWrite: true`；这会弹出权限确认，等用户同意后再执行。
- DDL 用 `CREATE TABLE IF NOT EXISTS`；批量写入前先小范围验证。

## 错误处理

- 「Connection not found」：重新 `database_list`，确认名称/ID。
- 语法错误：读返回的数据库原文修正后重试，不要改用 shell 里的 `mysql` / `psql`。
- 不要回退到 shell CLI，也不要自己拼接连接参数。
