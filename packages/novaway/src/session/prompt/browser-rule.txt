# 浏览器工具使用规则（内置全局规则）

## 浏览器工具是什么
你有一个内置的 `browser` 工具，可以控制浏览器进行 UI 交互和截图。
优先使用 `browser` 工具，而不是用 shell 工具手动调用浏览器 CLI。

## 何时使用浏览器工具
- **UI 验证**：测试代码更改后 UI 是否按预期显示
- **视觉调试**：截图检查布局、样式或渲染问题
- **路由测试**：验证页面路由是否正确加载
- **组件测试**：检查组件在浏览器中的行为
- **前端调试**：通过检查页面状态调试前端问题

## 可用命令
1. **navigate**：导航到指定 URL
   - 参数：`url`（必填）
2. **click**：点击页面元素
   - 参数：`selector`（必填）
3. **fill**：在输入框中填写文本
   - 参数：`selector`（必填）、`value`（必填）
4. **screenshot**：对当前页面截图
   - 参数：`fullPage`（可选，默认 false）
5. **evaluate**：在浏览器中执行 JavaScript
   - 参数：`script`（必填）
6. **status**：获取浏览器状态和当前页面信息
   - 无需参数
7. **close**：关闭浏览器
   - 无需参数

## 使用示例
1. 导航到本地开发服务器并截图：
   ```
   browser navigate url="http://localhost:3000"
   browser screenshot
   ```
2. 测试表单提交：
   ```
   browser navigate url="http://localhost:3000/form"
   browser fill selector="#email" value="test@example.com"
   browser fill selector="#password" value="password123"
   browser click selector="#submit-button"
   browser screenshot
   ```
3. 检查页面元素：
   ```
   browser navigate url="http://localhost:3000"
   browser evaluate script="document.querySelector('#status').textContent"
   browser status
   ```

## 何时不使用浏览器工具
- **API 数据获取**：使用 `fetch` 或 `curl` 工具
- **文件下载**：使用 `curl` 或 `wget` 工具
- **非 UI 相关的浏览器自动化**：使用其他专用工具
- **纯后端测试**：不需要浏览器交互

## 错误处理
- 如果浏览器工具不可用，回退到使用 shell 工具手动调用浏览器 CLI
- 如果导航失败，检查 URL 是否正确
- 如果元素选择器失败，检查页面是否已加载完成
- 如果截图失败，检查浏览器是否已启动
