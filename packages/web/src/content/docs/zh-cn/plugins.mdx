---
title: 插件
description: 编写自己的插件来扩展 NovaWay。
---

插件就是一个普通的 TypeScript / JavaScript 模块，导出一组**钩子**。NovaWay 运行时调用这些
钩子，你的代码因此可以读取对话、修改发给模型的请求、注册工具、甚至新增供应商。本页所有
示例都基于 `@novaway/plugin`。

---

## 快速开始

在项目里新建 `.novaway/plugin/hello.ts`：

```ts title=".novaway/plugin/hello.ts"
import type { Plugin } from "@novaway/plugin"

export default {
  id: "hello",
  server: (async () => ({
    "tool.execute.before": async (input, output) => {
      if (input.tool === "bash") {
        console.log("about to run:", output.args.command)
      }
    },
  })) satisfies Plugin,
}
```

启动 NovaWay 之后，每次调用 `bash` 工具都会打印出来。`.novaway/plugin/` 和
`.novaway/plugins/` 下的文件会被自动发现，不需要任何配置。

## 插件放在哪里

| 位置                            | 作用范围     | 加载方式   |
| ------------------------------- | ------------ | ---------- |
| `.novaway/plugin/*.ts`          | 项目         | 自动       |
| `.novaway/plugins/*.ts`         | 项目         | 自动       |
| `~/.config/novaway/plugin/*.ts` | 全局         | 自动       |
| `novaway.json` 的 `plugin` 数组 | 全局或项目   | 按 spec    |

`plugin` 数组支持 npm 包名、git 地址和本地路径：

```json title="novaway.json"
{
  "$schema": "https://novaway.ai/config.json",
  "plugin": [
    "./plugin/release-helper.ts",
    "novaway-plugin-git-hooks",
    "@my-org/novaway-plugin-audit@1.2.0",
    "some-plugin@git+https://gitee.com/my-org/some-plugin.git"
  ]
}
```

**npm 插件**在启动时由 Bun 安装，缓存在 `~/.cache/novaway/node_modules/`。**本地插件**直接
import；如果要在本地插件里用第三方包，需要在配置目录放一个 `package.json`（见
[依赖项](#dependencies)）。

加载顺序是：全局配置、项目配置、全局插件目录、项目插件目录。所有插件的所有钩子按这个顺序
依次执行。名称和版本都相同的 npm 包只加载一次。

## 插件的两种写法

### 带 id 的 default 导出（推荐）

```ts title=".novaway/plugin/release-helper.ts"
import type { Plugin } from "@novaway/plugin"

export default {
  id: "release-helper",
  server: (async ({ client, directory }) => {
    return {
      // 钩子
    }
  }) satisfies Plugin,
}
```

路径形式的插件必须提供 `id`，NovaWay 用它来去重、报错和热重载。

### 具名导出（简写）

```ts title=".novaway/plugin/release-helper.ts"
import type { Plugin } from "@novaway/plugin"

export const ReleaseHelper: Plugin = async ({ client, directory }) => {
  return {
    // 钩子
  }
}
```

一个模块可以用这种方式导出多个函数，每个都会被执行。准备发布给别人用的插件请用 `default`
写法。

### 传入选项

任何 spec 都可以带一个选项对象，作为插件的第二个参数：

```json title="novaway.json"
{
  "plugin": [["./plugin/audit.ts", { "endpoint": "https://audit.example.com" }]]
}
```

```ts title=".novaway/plugin/audit.ts"
export default {
  id: "audit",
  server: async (ctx, options) => {
    const endpoint = String(options?.endpoint ?? "")
    return {
      "session.idle": async () => {
        await fetch(endpoint, { method: "POST", body: JSON.stringify({ cwd: ctx.directory }) })
      },
    }
  },
}
```

## 插件上下文

你导出的函数会收到一个对象：

| 字段                     | 用途                                                   |
| ------------------------ | ------------------------------------------------------ |
| `client`                 | `@novaway/sdk` 客户端，用来调用正在运行的服务           |
| `project`                | 项目 id 和版本控制信息                                 |
| `directory`              | 会话工作目录，优先用它而不是 `process.cwd()`            |
| `worktree`               | 仓库根目录，适合拼稳定的相对路径                       |
| `serverUrl`              | 当前插件所服务的本地服务地址                           |
| `$`                      | Bun shell（[文档](https://bun.com/docs/runtime/shell)） |
| `experimental_workspace` | `register(type, adapter)`，注册远程工作区适配器         |

## 依赖项

本地插件和自定义工具可以使用外部 npm 包。在配置目录中添加一个 `package.json`，列出所需的
依赖项。

```json title=".novaway/package.json"
{
  "dependencies": {
    "shescape": "^2.1.0"
  }
}
```

NovaWay 会在启动时运行 `bun install` 来安装这些依赖项，之后你的插件和工具就可以导入它们。

```ts title=".novaway/plugin/safe-shell.ts"
import { escape } from "shescape"

export const SafeShell = async () => {
  return {
    "tool.execute.before": async (input, output) => {
      if (input.tool === "bash") {
        output.args.command = escape(output.args.command)
      }
    },
  }
}
```

## 钩子

直接原地修改 `output` 对象即可。从 `*.before` 之类的钩子里抛异常会中断这一次操作，并把错误
信息反馈给模型。

### 对话

| 钩子 | 输入 | 输出 |
| ---- | ---- | ---- |
| `chat.message` | `sessionID`、`agent`、`model`、`messageID`、`variant` | `message`、`parts` |
| `chat.params` | `sessionID`、`agent`、`model`、`provider`、`message` | `temperature`、`topP`、`topK`、`maxOutputTokens`、`options` |
| `chat.headers` | 同 `chat.params` | `headers` |
| `experimental.chat.system.transform` | `sessionID`、`model` | `system: string[]` |
| `experimental.chat.messages.transform` | — | `messages` |

### 工具

| 钩子 | 输入 | 输出 |
| ---- | ---- | ---- |
| `tool` | — | 工具 id 到 `tool()` 定义的映射 |
| `tool.definition` | `toolID` | `description`、`parameters` |
| `tool.execute.before` | `tool`、`sessionID`、`callID` | `args` |
| `tool.execute.after` | `tool`、`sessionID`、`callID`、`args` | `title`、`output`、`metadata` |

### 命令与 Shell

| 钩子 | 输入 | 输出 |
| ---- | ---- | ---- |
| `command.execute.before` | `command`、`sessionID`、`arguments` | `parts` |
| `shell.env` | `cwd`、`sessionID`、`callID` | `env` |

`shell.env` 同时作用于 shell 工具调用和 NovaWay 打开的终端，是注入凭据或项目变量的正确位置。

### 会话与压缩

| 钩子 | 输入 | 输出 |
| ---- | ---- | ---- |
| `experimental.session.compacting` | `sessionID` | `context: string[]`、`prompt?: string` |
| `experimental.compaction.autocontinue` | `sessionID`、`agent`、`model`、`provider`、`message`、`overflow` | `enabled: boolean` |
| `experimental.text.complete` | `sessionID`、`messageID`、`partID` | `text` |

### 供应商与鉴权

| 钩子 | 用途 |
| ---- | ---- |
| `auth` | 为某个供应商增加 `/connect` 流程（API key 或 OAuth） |
| `provider` | 提供或覆盖某个供应商的模型列表 |

### 生命周期

| 钩子 | 输入 | 用途 |
| ---- | ---- | ---- |
| `event` | `event` | 所有总线事件：`session.idle`、`message.updated`、`file.edited`、`session.error`、`todo.updated` 等 |
| `config` | `Config` | 合并后的配置，在启动完成前触发 |
| `hook` | `event`、`payload` | 内核生命周期事件，如 `SessionStart`、`PreToolUse`、`Stop`、`SubagentStart`。把 `output.result.decision` 设为 `"deny"` 即可拦截 |

## 示例

每个示例都是完整文件。保存到 `.novaway/plugin/` 后重启即可，不需要改配置。

---

### 发送通知

在特定事件发生时发送通知：

```ts title=".novaway/plugin/notify.ts"
import type { Plugin } from "@novaway/plugin"

export const Notify: Plugin = async ({ $ }) => {
  return {
    event: async ({ event }) => {
      if (event.type === "session.idle") {
        await $`osascript -e 'display notification "Session completed!" with title "NovaWay"'`
      }
    },
  }
}
```

这里用 `osascript` 在 macOS 上发送通知。Linux 用 `notify-send`，Windows 用 PowerShell 的
Toast 脚本。

:::note
NovaWay 桌面端在响应就绪或会话出错时本来就会发系统通知，所以通知类插件主要是给 CLI 和 TUI 用。
:::

### .env 保护

阻止 NovaWay 读取 `.env` 文件：

```ts title=".novaway/plugin/env-protection.ts"
import type { Plugin } from "@novaway/plugin"

export const EnvProtection: Plugin = async () => {
  return {
    "tool.execute.before": async (input, output) => {
      if (input.tool === "read" && String(output.args.filePath).includes(".env")) {
        throw new Error("Do not read .env files")
      }
    },
  }
}
```

### 注入环境变量

把环境变量注入每一次 Shell 执行，既包括工具调用，也包括 NovaWay 打开的终端：

```ts title=".novaway/plugin/inject-env.ts"
import type { Plugin } from "@novaway/plugin"

export const InjectEnv: Plugin = async ({ directory }) => {
  return {
    "shell.env": async (input, output) => {
      output.env.PROJECT_ROOT = input.cwd || directory
      output.env.NOVAWAY_TRACE = "1"
    },
  }
}
```

### 自定义工具

插件可以给模型加上可调用的工具：

```ts title=".novaway/plugin/custom-tools.ts"
import { type Plugin, tool } from "@novaway/plugin"

export const CustomTools: Plugin = async () => {
  return {
    tool: {
      mytool: tool({
        description: "This is a custom tool",
        args: {
          foo: tool.schema.string().describe("Anything"),
        },
        async execute(args, context) {
          return { title: "mytool", output: `Hello ${args.foo} from ${context.directory}` }
        },
      }),
    },
  }
}
```

`tool()` 有三个字段：

- `description`：给模型看的说明
- `args`：[Zod](https://zod.dev) 原始 shape，通过 `tool.schema` 访问
- `execute`：收到解析后的参数和工具上下文

工具上下文里有 `sessionID`、`messageID`、`agent`、`directory`、`worktree`，一个 `abort`
信号，以及 `metadata()`（实时更新工具卡片）和 `ask()`（申请权限）。完整 API 见
[自定义工具](/docs/custom-tools)。

:::note
如果插件工具与内置工具同名，插件工具优先。
:::

### 日志记录

用 `client.app.log()` 而不是 `console.log` 做结构化日志。TUI 里 `console.log` 的输出会被
吞掉，而服务端日志会落到 `~/.local/share/novaway/log`：

```ts title=".novaway/plugin/logging.ts"
import type { Plugin } from "@novaway/plugin"

export const Logging: Plugin = async ({ client }) => {
  return {
    event: async ({ event }) => {
      if (event.type !== "session.idle") return
      await client.app.log({
        body: {
          service: "logging",
          level: "info",
          message: "session idle",
          extra: { session: event.properties.sessionID },
        },
      })
    },
  }
}
```

日志级别是 `debug`、`info`、`warn`、`error`。客户端 API 见 [SDK](/docs/sdk)。

### 压缩钩子

自定义会话压缩时包含的上下文：

```ts title=".novaway/plugin/compaction.ts"
import type { Plugin } from "@novaway/plugin"

export const Compaction: Plugin = async () => {
  return {
    "experimental.session.compacting": async (input, output) => {
      output.context.push(`
## Custom Context

Include any state that should persist across compaction:
- Current task status
- Important decisions made
- Files being actively worked on
`)
    },
  }
}
```

`experimental.session.compacting` 在模型生成续接摘要之前触发，用来补上默认提示词会漏掉的
领域上下文。

也可以直接给 `output.prompt` 赋值来整体替换压缩提示词：

```ts title=".novaway/plugin/custom-compaction.ts"
import type { Plugin } from "@novaway/plugin"

export const CustomCompaction: Plugin = async () => {
  return {
    "experimental.session.compacting": async (input, output) => {
      output.prompt = `
You are generating a continuation prompt for a multi-agent session.

Summarize:
1. The current task and its status
2. Which files are being modified and by whom
3. Any blockers or dependencies between agents
4. The next steps to complete the work

Format as a structured prompt that a new agent can use to resume work.
`
    },
  }
}
```

设置了 `output.prompt` 之后默认提示词会被整体替换，`output.context` 不再生效。

import type { Plugin } from "@novaway/plugin"

export const TraceHeaders: Plugin = async ({ project }) => {

### 从内核钩子拦截动作

`hook` 会收到全部内核生命周期事件，包括那些没有专属钩子的事件：

```ts title=".novaway/plugin/kernel-policy.ts"
import type { Plugin } from "@novaway/plugin"

export const KernelPolicy: Plugin = async () => {
  return {
    hook: async (input, output) => {
      if (input.event === "PreToolUse" && input.payload.tool === "write") {
        output.result.decision = "deny"
        output.result.reason = "该工作区禁止写文件"
      }
    },
  }
}
```

## 供应商与鉴权

`auth` 钩子会在 `/connect` 里加一项：

```ts title=".novaway/plugin/my-gateway-auth.ts"
import type { Plugin } from "@novaway/plugin"

export const MyGatewayAuth: Plugin = async () => {
  return {
    auth: {
      provider: "my-gateway",
      methods: [
        {
          type: "api",
          label: "API key",
          prompts: [{ type: "text", key: "accountId", message: "Account id", placeholder: "acct_..." }],
        },
      ],
    },
  }
}
```

需要走浏览器回跳时用 `type: "oauth"` 搭配 `method: "auto"` 或 `method: "code"`。内置的
GitHub Copilot、GitLab、Codex、Cloudflare、Azure、DigitalOcean 都是这样实现的。

`provider` 钩子给**已经存在**的供应商提供模型列表 —— 供应商本身在 `novaway.json` 里定义
（或由内置插件创建），这里只负责填模型。每个条目都是一条完整的 v2 `Model` 记录：

```ts title=".novaway/plugin/my-gateway-models.ts"
import type { Plugin } from "@novaway/plugin"
import type { Model } from "@novaway/sdk/v2"

export const MyGatewayModels: Plugin = async () => {
  return {
    provider: {
      id: "my-gateway",
      // 每条记录都要满足 Model 的完整结构，通常是取一个现有模型再覆盖字段
      models: async () => ({
        "fast-1": { ...someExistingModel, id: "fast-1", name: "Fast 1" } as Model,
      }),
    },
  }
}
```

这个钩子还会拿到供应商信息和已保存的凭据，所以可以直接去上游接口拉列表，而不是写死。

## 工作区

`experimental_workspace.register(type, adapter)` 教 NovaWay 如何创建和销毁远程工作区。
适配器接口从 `@novaway/plugin` 导出为 `WorkspaceAdapter`：`configure`、`create`、`remove`、
`target`。

## TUI 插件

改变终端界面的插件导出 `tui` 而不是 `server`：

```ts title=".novaway/plugin/my-tui.ts"
import type { TuiPlugin } from "@novaway/plugin/tui"

export default {
  id: "my-tui",
  tui: (async (api) => ({
    // commands, dialogs, keymaps, slots, toast
  })) satisfies TuiPlugin,
}
```

一个模块只能导出 `server` 或 `tui` 其中之一。命令、对话框、输入框、插槽、键位映射、提示音
都在 `api` 对象上，完整接口见 `@novaway/plugin/tui` 的类型定义。

## 调试

- `novaway debug info` 列出所有配置合并后 NovaWay 实际解析到的插件。
- `novaway plugin <module>` 安装 npm 插件并写入配置。
- `--pure` 关闭全部外部插件，是排查「是不是某个插件干的」最快的方法。
- 钩子报错会带插件 id 记进日志。`tool.execute.before` 抛异常只中断那一次调用，不会终止会话。

## 迁移

从其他 agent 移植过来的插件通常要改四处：

1. **包名** —— `@opencode-ai/plugin` 改成 `@novaway/plugin`，`@opencode-ai/sdk` 改成
   `@novaway/sdk`。
2. **工厂函数** —— `createOpencode` 改成 `createNovaway`，`createOpencodeClient` 改成
   `createNovawayClient`。
3. **配置键** —— `opencode.json` 改成 `novaway.json`，`.opencode/` 改成 `.novaway/`。
4. **钩子名** —— 以本文上方的表格为准，表里没有的钩子不会被调用。

NovaWay 运行时不会把 `@opencode-ai/*` 解析到自己的包上，所以 import 了那些包的插件必须先改
import 才能加载。
