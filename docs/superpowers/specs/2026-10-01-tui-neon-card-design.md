# TUI 卡片化 · 霓虹玻璃视觉升级设计文档

**日期**: 2026-10-01
**状态**: 待评审
**版本**: 1.0

## 1. 概述

对 `packages/tui` 的会话界面做一次整体视觉升级：以「霓虹玻璃 Neon Glass」为设计语言，
把侧栏、Tab、消息区、输入区统一为渐变描边卡片；并新增**双视图**——默认气泡视图 +
`/layout flow` 流程图画布视图（多列变尺寸节点、箭头标注连线、并发分叉、结束节点、
多轮追加、节点拖动）。

视觉方案已通过浏览器 mockup 迭代确认（v1–v7，7 轮），本文档固化全部设计决策，
作为实现规划（writing-plans）的输入。

## 2. 背景与动机

### 现状

- TUI 基于 OpenTUI（`@opentui/core` + `@opentui/solid`）+ SolidJS + Yoga flexbox，60fps。
- 主界面集中在 `packages/tui/src/routes/session/index.tsx`（约 3300 行），
  侧栏 `session/sidebar.tsx`、底栏 `session/footer.tsx`、边框原语 `ui/border.ts`。
- 主题系统：`theme/index.ts` 定义约 60 个语义 token（`{dark, light}` 变体），
  `context/theme.tsx` 提供 35 个内置 JSON 主题 + `resolveTheme(themeJson, mode)`。
- 动画基础设施薄弱：仅 `util/anim-spinner.ts` 的 crush 式 `animFrames` 乱码流。
- 无卡片化视觉、无入场/切换动效、消息区只有单一线性气泡流。

### 设计目标

1. 全局统一「霓虹玻璃」卡片视觉：渐变描边 + 不透明深底 + HUD 角标 + 缓动动效。
2. 深浅模式与全部主题自适应：所有颜色走语义 token，渐变端点 = 主题三色变量。
3. 新增 `/layout` 命令切换气泡 / 流程图双视图；流程图支持并发分叉、结束节点、
   多轮追加、点击详情、节点拖动。
4. 思考/工作指示复用 crush 乱码流，替代普通转点。

### 非目标

- 不改服务端、不改消息数据模型（视图只是同一数据的两种渲染形态）。
- 不做主题编辑器；不新增主题格式。
- 不追求与 mockup 像素级一致（TUI 字符网格有自己的表达，见 §9 降级策略）。

## 3. 视觉语言：霓虹玻璃（Neon Glass）

以 mockup `card-design-v7.html` 为视觉基准（文件位于
`.superpowers/brainstorm/311-1790840200/content/`，本地服务 http://localhost:55134）。

### 3.1 八要素

| # | 要素 | 说明 |
|---|------|------|
| ① | 霓虹渐变外框 | 所有卡片 1.5px 粉→紫→青渐变描边（`--gb-main`），hover 光晕加深 |
| ② | 深色实底 | 面板/气泡统一**不透明深色实底**，渐变只出现在边框一圈（用户两次否决了染色底） |
| ③ | 语义变体 | 提示=琥珀框、用户消息=粉紫框、助手=青蓝框、思考=紫青框、编辑=琥橙框、结束=绿框；语义靠边框色不靠底色 |
| ④ | 全局动效 | 统一 `expo-out cubic-bezier(.16,1,.3,1)`；阶梯入场、侧滑换页、HUD 角标、聚焦流动描边+扫光 |
| ⑤ | 深浅自适应 | 全部颜色走 CSS 变量/主题 token；浅色模式整套翻转（白底卡片+加深渐变+柔和阴影） |
| ⑥ | 主题驱动 | 渐变边框端点 = 主题三色变量；切换 35 个内置主题时边框/高亮/发光随之变化 |
| ⑦ | 工作指示 | crush 式乱码流（复用 `animFrames`）：一条乱码带持续飘过 + 实时计时 |
| ⑧ | 双视图 | 默认气泡；`/layout flow` 切流程图画布（详见 §8） |

### 3.2 主题与 token 规则

- 新增/复用 token（命名以 `theme/index.ts` 现有风格为准）：
  - `gb.start / gb.mid / gb.end`：渐变三端色（默认粉/紫/青），随主题切换；
  - `card.border / card.bg / card.shadow`：卡片描边、实底、阴影；
  - `hud.tick / rail.grad`：HUD 角标与导轨色。
- **禁止用 `background` 简写承载渐变文字**（会重置 `background-clip: text`），
  必须用 `background-image`。此为 mockup 阶段实际踩过的坑。
- 浅色模式：`mode === "light"` 时实底翻白、渐变加深、阴影柔化（token 变体承载，
  不写散落的 if）。

## 4. 组件级改造（按区域）

实现落点以 `packages/tui/src/routes/session/` 为主，视觉原语沉淀到 `ui/`。

| 区域 | 改造 |
|------|------|
| Titlebar | 下沿加**彩虹渐变导轨**（一条细渐变条，随主题三色） |
| 侧栏 `sidebar.tsx` | 分区面板卡片化：渐变描边 + 圆角 + HUD 角标；选中行加内衬高亮；与聊天区之间加竖向发光导轨 |
| Tab 栏 | 活动 Tab 卡片化（描边 + 底光）；右侧 pill 组件统一（含新增 `视图·气泡/流程图` 状态 pill） |
| 消息区 | 气泡视图：用户/助手气泡卡片化（语义边框色），工具折叠卡、思考卡同款卡片；保留 stagger 阶梯入场 |
| Prompt | 聚焦时**流动渐变描边 + 扫光**扫过边框；快捷键提示行常驻（含 `/layout` 提示） |
| Footer | 状态 pill 统一卡片风格 |
| 思考指示 | `animFrames` 乱码带 + 实时计时（`0.0s`），替代转点 |
| 新原语 | `ui/card.tsx`：`Card` 组件（边框色/角标/hover/handoff 属性），各处复用，避免样式散落 |

## 5. 动效系统

- 统一缓动：`expo-out = cubic-bezier(.16, 1, .3, 1)`，所有过渡不混用其他曲线。
- 入场：卡片阶梯入场（每级 +60–90ms 延迟，opacity+translateY 合成）。
- 视图切换：`viewIn`（淡入+上移 12px），切换时重新播放（display 变化重置）。
- 聚焦：prompt 描边颜色沿边流动 + 高光扫过，周期 4s。
- 流程图专属：节点 `cardIn` 按流程顺序延迟、连线**逐段描画**（等价 dashoffset）、
  标注弹入（scale 0.8→1）。
- 实现约束：Effect v4 无 `Effect.fork`，动画 tick 用现有渲染循环/`anim-spinner`
  模式；避免 `Effect.sleep` 等待（见 `packages/novaway/test/AGENTS.md` 约束）。
- 帧率目标 60fps 不倒退：动画仅合成层属性，不触发布局重排。

## 6. crush 工作指示

- 复用 `util/anim-spinner.ts` 的 `animFrames` 字符集，视觉改为**持续滚动的乱码带**
  （约 60 格，波形透明度，12% 概率高亮青/紫），右侧跟实时计时。
- 语义不变：仍在 thinking 消息内指示"正在工作"，随消息完成停止。

## 7. 双视图与 `/layout` 命令

- 新增 slash 命令 `/layout bubble`（默认）与 `/layout flow`，加入现有命令系统
  （与 `/new`、`/models` 同机制），Tab 栏右侧 pill 显示当前视图。
- 两视图共享同一消息数据，仅渲染形态不同；切换不动数据、不打断运行中任务。
- 视图选择为会话级状态（可持久化到现有会话设置，具体落点实现时确定）。

## 8. 流程图画布视图（`/layout flow`）

### 8.1 布局规则

- **画布**：会话消息区变为绝对定位画布（Yoga absolute / 网格坐标），节点为
  变尺寸卡片（约 130–180 列宽 × 68–110 行高区间，接近长方形，尺寸随内容）。
- **多列蛇形**：一轮流程从画布**最左**开始，向右推进；行尾折返向下，再从左/右续排，
  不限于单列纵排。
- **自动布局**：按消息事件序列生成节点坐标（简单分层/行优先布局）；用户拖动后
  记住手动位置，新节点不覆盖已占用区域。

### 8.2 节点

- 五类节点 + 结束节点，语义边框色见 §3.1 ③：
  用户输入(粉紫) / 任务拆解(紫蓝) / 工具调用(青蓝) / 子代理(紫蓝) / 编辑(琥橙) /
  回复(绿青) / ⏹ 结束(绿胶囊，圆角胶囊形)。
- 节点头部：状态点 + 类型 + 元信息（耗时/结果/时间），标题 1–2 行；
  最新回复带「最新」徽标并**默认展开详情**。
- **点击节点弹出详情气泡**（展开内容悬浮显示，不撑开布局、不推挤连线）；
  再点收起。结束节点不可点击展开。
- **节点可拖动**（用户确认写入设计）：按住拖拽移动，连线与标注实时跟随重绘；
  松开不误触详情。

### 8.3 连线

- 连线为**带箭头的曲线 + 线上胶囊标注**（如「并行·工具」「诊断建议」
  「edit +6 −2」「✓ 18 passed」），箭头色随语义。
- **并发分叉**：同一节点可发出多条箭头指向不同节点（如任务拆解 → 工具 ∥ 子代理），
  支持多出度与汇聚（两支 → 编辑）。
- TUI 字符渲染：折线用 box-drawing 字符（`─│╭╮╰╯` 等）+ 箭头字符（`→ ↓ ←`），
  拐角圆滑降级为直角；标注放在线上的胶囊段（背景块字符）。
  mockup 的 SVG 曲线为理想形态，字符折线为 TUI 落地形态。

### 8.4 多轮追加（用户确认方案：追加新一轮）

- 每轮以 ⏹ 结束节点收尾；用户再发消息时，**新一轮从画布最左开始**（与上一轮
  起点垂直对齐），轮次之间加虚线分隔 +「第 N 轮」标记。
- 一轮内节点顺序：新消息 →（上一轮 END 连出「新消息」曲线）→ 处理节点 →
  回复 → END。历史全保留，画布纵向生长。
- 长会话保护：超过 N 轮（建议 5）时旧轮折叠为一行摘要节点，可点开展开
  （实现阶段定具体交互）。

### 8.5 交互入口

- 键盘：`/layout` 命令切换；流程图内 Tab/方向键在节点间移动焦点，Enter 展开详情。
- 鼠标：点击展开、拖动移动（依赖 OpenTUI 鼠标事件，见 §9 spike）。

## 9. TUI 实现映射与降级策略

| Mockup 概念 | TUI 落地 | 优先级/降级 |
|-------------|----------|------------|
| 渐变描边卡片 | 边框字符**逐字符 truecolor 插值**（自绘边框四边，非单色 border 属性） | P0；若性能不达标降级为语义单色边框 + 双端渐变角标 |
| 彩虹导轨 | 一行逐字符插值色块 | P0 |
| HUD 角标 | 卡片四角特殊字符（`╭╮╰╯` 加亮变体） | P0 |
| SVG 曲线箭头 | box-drawing 字符折线 + 箭头字符，直角拐弯 | P0（曲线为 P2 视觉增强） |
| 画布绝对定位 | Yoga `position: absolute`（OpenTUI 支持） | P0 |
| 节点拖动 | OpenTUI 鼠标事件（mousedown/move/up） | **P0 前置 spike**：先验证鼠标事件在目标终端可用；不可用则降级为键盘移动（焦点节点 + 方向键微调），拖动功能标为条件性交付 |
| 详情弹层 | 覆盖层组件（z-index 提升的浮层） | P0 |
| CSS 动画/缓动 | 自有 tween tick（对齐 expo-out 曲线） | P0；复用 `anim-spinner` 的帧驱动模式 |
| `backdrop-filter`/阴影 | 降级：边框外一圈暗色描边模拟深度 | P0（阴影不可用即降级，不影响布局） |

### 9.1 前置 Spike（实现计划第一步）

1. **鼠标事件**：OpenTUI 在 Windows Terminal / iTerm 下的 mouse down/move/up
   支持情况与坐标精度——决定拖动走鼠标还是键盘。
2. **逐字符渐变边框**：手绘边框字符逐字符设色的渲染开销（长会话多卡片场景）。

### 9.2 涉及文件（预期）

- `routes/session/index.tsx`：布局骨架、双视图切换、prompt 扫光。
- `routes/session/sidebar.tsx`、`footer.tsx`：卡片化。
- `ui/card.tsx`（新）：Card 原语；`ui/border.ts`：渐变边框绘制扩展。
- `routes/session/flow-canvas.tsx`（新）：流程图渲染、布局、拖动、详情浮层。
- `theme/index.ts`、`context/theme.tsx`：新增 token。
- `util/anim-spinner.ts`：乱码带指示。
- slash 命令注册处（`/layout`）。

## 10. 测试与验收

- `bun lint` → `bun typecheck` → `cd packages/novaway && bun test --timeout 30000`
  （测试不得从仓库根运行）。
- 视觉验收对照 mockup v7 要素清单（§3.1 八要素逐项过）。
- 主题验收：深/浅模式 + 至少 3 个内置主题（霓虹/极地/熔岩风格）切换无破色。
- 流程图验收：并发分叉、结束节点、多轮追加左起、拖动或键盘移动连线跟随、
  `/layout` 切换不丢消息状态。
- TUI 交互类逻辑按 `packages/novaway/test/AGENTS.md` 模式补测试
  （`testEffect`、避免固定 sleep）。

## 11. 风险与开放问题

- **鼠标事件支持**（最大不确定性）：spike 前无法确认拖动可用性，已有键盘降级路径。
- **逐字符渐变性能**：多卡片 + 长会话下的帧率，spike 验证。
- **index.tsx 体量**：约 3300 行，双视图引入需克制拆分（新增 flow-canvas 独立文件）。
- **旧轮折叠交互**（§8.4）：具体展开方式实现阶段确认。
- **视图状态持久化落点**：会话级还是全局级，实现阶段确认。
