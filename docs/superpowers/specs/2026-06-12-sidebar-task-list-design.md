# 侧边栏任务列表布局设计文档

**日期**: 2026-06-12  
**状态**: 已确认  
**版本**: 1.0

## 1. 概述

将当前嵌入在聊天区域的任务列表（TodoWrite组件）移动到侧边栏的独立区域，采用上下分割布局，使任务管理更加清晰和专注。

## 2. 背景与动机

### 当前问题
- 任务列表嵌入在聊天消息流中，与对话内容混杂
- 用户需要滚动聊天记录才能查看完整任务列表
- 任务状态变化会打断聊天流程的阅读

### 设计目标
- 将任务列表独立显示，提供更好的可读性
- 保持任务状态与聊天区域的实时同步
- 不干扰现有的聊天交互流程

## 3. 设计方案

### 布局结构
```
┌─────────────────────────────────────┐
│            聊天区域                  │
│  ┌─────────────────────────────┐   │
│  │  用户消息                    │   │
│  │  AI回复                     │   │
│  │  任务列表（当前在聊天中）     │   │
│  └─────────────────────────────┘   │
│  ┌─────────────────────────────┐   │
│  │  输入框                     │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│  侧边栏（右侧）                     │
│  ┌─────────────────────────────┐   │
│  │  文件树tab区域               │   │
│  │  所有文件 | 审查 | 更改 | 数据库│   │
│  │  ┌───────────────────────┐ │   │
│  │  │  文件树内容            │ │   │
│  │  └───────────────────────┘ │   │
│  ├─────────────────────────────┤   │
│  │  任务列表区域               │   │
│  │  ┌───────────────────────┐ │   │
│  │  │  任务1 ✓              │ │   │
│  │  │  任务2 ✓              │ │   │
│  │  │  任务3 ●              │ │   │
│  │  │  任务4 ○              │ │   │
│  │  └───────────────────────┘ │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

### 详细设计

#### 3.1 侧边栏分割
- **分割方式**: 垂直分割（上下）
- **默认比例**: 上半部分50%，下半部分50%
- **分割线**: 可拖拽调整比例的分割线
- **最小高度**: 上下部分各至少100px

#### 3.2 上半部分：文件树区域
- **位置**: 侧边栏顶部
- **内容**: 现有的文件树tab（所有文件、审查、更改、数据库）
- **行为**: 保持现有功能不变
- **高度**: 可通过分割线调节

#### 3.3 下半部分：任务列表区域
- **位置**: 侧边栏底部
- **标题栏**: 显示"任务列表"标题和完成进度（如"2/5 已完成"）
- **折叠功能**: 可点击标题栏折叠/展开任务列表
- **任务项**: 每个任务项显示状态图标和任务描述
- **状态同步**: 与聊天区域的任务状态实时同步

#### 3.4 任务状态显示
- **已完成**: 绿色对勾图标 + 删除线文本
- **进行中**: 橙色圆点图标 + 加粗文本
- **待办**: 灰色圆圈图标 + 普通文本

#### 3.5 响应式设计
- **桌面端**: 侧边栏显示，任务列表独立区域
- **平板端**: 侧边栏可折叠，任务列表可收起
- **移动端**: 任务列表可通过按钮触发显示

## 4. 技术实现

### 4.1 组件修改
1. **session-side-panel.tsx**: 修改侧边栏布局，添加垂直分割
2. **新增TaskList组件**: 独立的任务列表显示组件
3. **修改任务同步逻辑**: 确保任务状态在聊天和侧边栏间同步

### 4.2 状态管理
- **任务状态**: 从聊天消息中提取任务状态
- **布局状态**: 保存侧边栏分割比例的用户偏好
- **折叠状态**: 保存任务列表的折叠状态

### 4.3 样式实现
- 使用现有的设计系统变量（颜色、间距、字体）
- 遵循现有的组件样式规范
- 支持深色/浅色主题

## 5. 交互设计

### 5.1 分割线交互
- **拖拽调整**: 拖拽分割线调整上下比例
- **双击重置**: 双击分割线重置为50%/50%
- **最小尺寸**: 拖拽时确保上下部分不小于100px

### 5.2 任务列表交互
- **折叠/展开**: 点击标题栏折叠或展开任务列表
- **任务状态**: 任务状态与聊天区域实时同步
- **滚动**: 任务列表内容过多时支持滚动

### 5.3 键盘快捷键
- **Ctrl/Cmd + T**: 切换任务列表显示/隐藏
- **Ctrl/Cmd + Shift + T**: 折叠/展开任务列表

## 7. 风险评估

### 7.1 技术风险
- **状态同步复杂性**: 需要确保任务状态在多个组件间实时同步
- **布局兼容性**: 需要处理不同屏幕尺寸的布局适配
- **性能影响**: 任务列表的实时更新可能影响性能

### 7.2 缓解措施
- 使用现有的状态管理机制，减少新增复杂性
- 渐进式增强，确保核心功能在不同设备上可用
- 性能监控和优化，确保流畅的用户体验
