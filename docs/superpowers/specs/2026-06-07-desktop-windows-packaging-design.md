# 桌面版 Windows 打包设计

**日期**：2026-06-07
**状态**：待评审
**范围**：打包流程配置，无代码修改

## 目标

为 NovaWay 桌面版打包 Windows 安装程序（.exe），用于团队分发和测试。

## 非目标

- 不修改现有打包配置
- 不添加代码签名功能
- 不打包其他平台（macOS、Linux）
- 不修改应用功能代码

## 探索结论

- **打包工具**：项目使用 electron-builder 进行打包，配置在 `packages/desktop/electron-builder.config.ts`
- **现有脚本**：`package.json` 中已配置 `package:win` 脚本
- **输出格式**：Windows 默认使用 NSIS 安装程序格式
- **签名配置**：支持代码签名，但可通过环境变量跳过

## 设计

### 打包参数

| 参数 | 值      | 说明                     |
| ---- | ------- | ------------------------ |
| 平台 | Windows | 仅打包 Windows 版本      |
| 架构 | x64     | 适用于大多数现代电脑     |
| 格式 | NSIS    | 标准 Windows 安装程序    |
| 签名 | 无      | 开发测试用，跳过代码签名 |
| 渠道 | dev     | 开发版本，不需要发布配置 |

### 打包步骤

```bash
# 1. 进入桌面包目录
cd packages/desktop

# 2. 一键构建和打包
bun run build && bun run package:win
```

### 输出结果

- **输出目录**：`packages/desktop/dist/`
- **文件名格式**：`novaway-desktop-win32-x64.exe`
- **文件大小**：预计 100-200MB（包含 Electron 运行时）
- **安装程序类型**：NSIS 单文件安装程序

### 分发方式

1. 将 `dist/novaway-desktop-win32-x64.exe` 上传到团队共享位置
2. 团队成员下载安装程序
3. 运行安装程序，按照向导完成安装
4. 安装后可在开始菜单找到 NovaWay 应用

### 注意事项

- **Windows 警告**：无签名版本会触发 Windows Defender 警告，需点击"仍要运行"
- **网络访问**：首次启动可能需要允许网络访问（用于 API 通信）
- **自动更新**：安装程序包含自动更新功能，但需要签名才能正常工作
- **磁盘空间**：安装需要约 500MB 磁盘空间

## 边界与不变量

- **不修改配置**：完全使用现有 electron-builder 配置
- **无签名**：跳过代码签名，适合内部测试分发
- **单平台**：仅打包 Windows 版本，不影响其他平台
- **开发版本**：使用 dev 渠道配置，无需发布到 GitHub

## 测试验证

打包完成后，验证以下内容：

1. **文件存在**：检查 `packages/desktop/dist/` 目录下是否生成 `.exe` 文件
2. **文件大小**：确认文件大小在合理范围内（100-200MB）
3. **安装测试**：在 Windows 电脑上运行安装程序，验证安装过程
4. **启动测试**：安装后启动应用，验证基本功能正常

## 范围与风险

- **范围**：打包流程配置，无代码修改
- **风险**：
  1. **依赖缺失**：如果缺少原生依赖，打包可能失败 → 需要先运行 `bun install`
  2. **磁盘空间不足**：打包需要临时空间 → 确保至少 1GB 可用空间
  3. **网络问题**：下载 Electron 依赖可能失败 → 确保网络连接正常
