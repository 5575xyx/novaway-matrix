# 侧边栏UI布局重新设计

## 概述

重新设计侧边栏UI布局，移除独立的侧边项目栏，将项目功能集成到任务会话栏中，提供更简洁的用户体验。

## 需求

### 核心需求
- 移除60px宽的侧边项目栏
- 任务会话栏默认展开显示
- 项目功能集成到任务会话栏顶部
- 项目行可展开/折叠，显示会话列表

### 功能保持
- 项目切换功能
- 项目拖拽排序
- 项目右键菜单（编辑、移动到模式、工作空间切换等）
- 工作空间管理

### 交互规则
- 当前项目默认展开，其他项目折叠
- 用户可手动展开/折叠项目
- 侧边栏宽度244px，支持拖拽调整

## 设计方案

### 方案选择
采用**渐进式重构**（方案A），保留现有组件结构，主要修改UI层。

### 组件结构

#### 修改的组件
| 组件 | 文件 | 变更 |
|------|------|------|
| `SidebarContent` | `sidebar-shell.tsx` | 移除侧边项目栏渲染，只保留面板区域 |
| `SortableProject` | `sidebar-project.tsx` | 从图标变为可展开卡片，集成会话列表 |
| `ProjectTile` | `sidebar-project.tsx` | 重命名为 `ProjectCard`，显示名称+路径 |
| `SidebarPanel` | `layout.tsx` | 移除，功能合并到 `SortableProject` |

#### 新增的组件
| 组件 | 文件 | 用途 |
|------|------|------|
| `ProjectExpandButton` | `sidebar-project.tsx` | 展开/折叠按钮 |
| `ProjectSessionList` | `sidebar-project.tsx` | 项目下的会话列表 |

#### 移除的组件
| 组件 | 原因 |
|------|------|
| `ProjectPreviewPanel` | 悬停预览不再需要 |

### 交互流程

#### 项目切换
```
点击项目卡片 → 切换到该项目 → 默认展开该项目的会话列表
```

#### 展开/折叠
```
点击展开按钮 → 展开/折叠该项目的会话列表
当前项目默认展开，其他项目默认折叠
```

#### 拖拽排序
```
拖拽项目卡片 → 实时预览位置 → 释放后保存排序
```

#### 右键菜单
```
右键点击项目 → 显示菜单（编辑、移动到模式、工作空间切换等）
保持现有右键菜单功能不变
```

#### 样式规范
- 项目名称：`text-14-medium text-text-strong`
- 项目路径：`text-12-regular text-text-weak`
- 当前项目背景：`bg-surface-raised-base-hover`
- 普通项目背景：`bg-transparent`
- 展开/折叠按钮：右侧对齐，图标 `chevron-down`/`chevron-right`

### 数据流与状态管理

#### 状态保留
- `workspaceExpanded` - 控制项目展开/折叠状态
- `workspaceOrder` - 项目排序
- `activeProject` - 当前选中项目

#### 状态调整
- 移除 `hoverProject` 相关状态（悬停预览不再需要）
- 移除 `peekProject` 相关状态（侧面预览不再需要）

#### 数据流
```
用户点击项目 
  → layout.projects.open(directory) 
  → navigateToProject(directory) 
  → 设置当前项目展开状态为 true
  → 其他项目保持折叠状态
```

### 响应式与移动端适配

#### 桌面端（xl及以上）
- 侧边栏宽度：244px（可拖拽调整，范围：244px - 窗口宽度*0.3+64px）
- 支持拖拽调整宽度
- 移除悬停预览功能

#### 移动端（xl以下）
- 侧边栏：全屏抽屉，从左侧滑入
- 使用相同的 `SidebarContent` 组件
- 通过 `mobile` 属性区分移动端行为

#### 断点
- 保持现有断点 `xl` (1280px)
- 移动端显示为全屏抽屉
