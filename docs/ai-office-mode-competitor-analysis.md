# AI 办公模式重构：竞品分析与设计建议

生成时间：2026-08-04

## 1. 研究目标

本次调研围绕三个问题展开：

1. 市面主流 AI 办公产品如何设计“模式进入、场景切换、对话与产物”的核心交互。
2. AI PPT 产品如何做到“可生成、可编辑、可交付”，而不是只输出一篇 Markdown 草稿。
3. 当前 NovaWay 办公模式已经有哪些能力，哪些地方可以直接复用，哪些需要重构补齐。

## 2. 市场结论

AI 办公产品正在从“聊天框里的长答案”转向“以任务为中心、以产物为交付物”的办公工作台。当前主流产品的共同趋势是：

- **统一入口**：用户先进入一个 AI 办公工作台，而不是散落在文档、表格、会议等不同软件里。
- **场景切换器**：在输入框附近直接切换“文档、PPT、会议、写作、设计”等工作台，切换后右侧画布和上下文一起变化。
- **先确认再执行**：复杂任务先结构化追问、输出大纲或设计计划，确认后再生成。
- **产物优先**：生成结果落到本地或项目文件，支持继续编辑、版本回溯、预览和导出。
- **全链路交付**：不仅生成内容，还补齐模板、图表、配图、演讲备注、导出和演示能力。
- **长期记忆**：记住用户偏好、公司模板、汇报风格，让重复工作越用越顺。

## 3. 重点竞品分析

### 3.1 Trae Work

来源：Trae Work 官方文档。

Trae Work 的核心不是做成一个更大的聊天工具，而是做成“任务工作台”。它把用户分成 Work、Code、Design 三种模式，并支持网页端、桌面端和移动端联动。

值得借鉴的亮点：

- 三种模式在界面左上角切换，进入某个模式后会得到与该模式匹配的任务体验。
- 输入支持文字、语音、附件、图片、斜杠命令和 Skill，上下文很丰富。
- 任务面板集中展示待办计划、任务产物、参考信息、浏览器预览和终端，用户不用在多个工具间切换。
- 复杂任务支持 Spec 与 Plan 工作流：先生成 spec、tasks、checklist 或 plan.md，用户确认后再执行。
- 模板库把常见办公任务做成“做同款”，点击后自动填入任务说明、执行步骤和交付要求。
- 产物可以预览、编辑、添加到对话继续修改，也能导出 HTML、PNG、JPG、ZIP 等格式。
- 任务支持置顶、重命名、删除、全局搜索，并把多端任务状态同步到移动端。

### 3.2 QoderWork

来源：QoderWork 官方文档与阿里云帮助中心。

QoderWork 是最接近用户描述的“场景切换器 + 办公工作台”形态。它的核心设计是：底部输入框附近放一个工作台切换器，默认是“通用”，可以切换到“写作”“幻灯片”“设计”等工作台。

值得借鉴的亮点：

- 工作台切换器放在输入框左下角，位置非常显眼，而不是藏在设置里。
- 同一个对话可以切换不同工作台，切换后右侧画布变成对应场景的专属视图。
- 写作工作台把 AI 输出变成 Markdown 文件树 + 编辑器，支持只读/编辑切换、版本选择、PDF 导出。
- 写作前可选择“语气”和“工作目录”，Agent 后续轮次基于用户手动修改继续。
- 幻灯片工作台使用 16:9 HTML 画布，包含“幻灯片 / 大纲 / 文件”三个页签。
- Agent 会先输出大纲，每节带简介和版式标签，用户接受后才开始生成页面。
- 生成过程支持逐页填充、追加指令、打断生成、中途切换模型。
- 最终成果支持放映、导出 PPTX / PDF / HTML，还能保存为模板。
- 设计工作台引入 Questions、Design Plan、Nudge 三个机制：先追问、再确认计划、生成后用可调参数微调。

### 3.3 ChatGPT Work

来源：OpenAI 官方页面。

ChatGPT Work 的重点不是“更聪明的聊天”，而是“能持续工作数小时的 Agent”。它可以跨应用和文件收集信息，生成文档、演示文稿、电子表格和 Web 应用。

值得借鉴的亮点：

- 用户只需给出最终目标，Agent 自动拆解任务、规划执行路径并持续跟进。
- 复杂项目以任务形式运行，用户可以随时查看进度、回答问题、调整方向、审批关键操作。
- 支持插件和连接器，把 Slack、Teams、Drive、SharePoint、日历、CRM 等外部上下文带进任务。
- 支持定时任务，例如每周更新会议议程、每天检查数据面板、收到新反馈时更新演示文稿。
- 桌面端支持内置浏览器和计算机使用，跨网页与本地文件完成任务。
- 强调模板和参考文件，Agent 生成资料时能遵循用户模板和偏好格式。

### 3.4 商汤办公小浣熊

来源：量子位、雷峰网、商汤官方发布。

小浣熊 3.0 是典型的“AI 办公搭子”路线，重点解决“AI 只给草稿、不给成品”的问题。

值得借鉴的亮点：

- 从原始碎片化信息理解意图，自动规划脚本，生成包含大纲、版式、插图、数据图表且视觉统一的完整 PPT。
- 支持百万级数据量级分析，把模糊目标拆解成可执行计划，并生成有背景和前瞻性的分析报告。
- 强调“交付跃迁”：从生成草稿升级到交付成果，云端与本地都支持图表、图片、文字元素快速编辑。
- 可编辑 AI PPT 支持“一键生成、页页可改”，单页可独立重新生成、文案润色、手动改字、替换图标。
- 支持上传公司模板、品牌手册或私人风格，自动提取颜色、布局和字体习惯。
- 提供素材库，支持上传图片、Logo 和配图，按需搜索调用。
- 生成全过程透明可追踪，后台任务完成后自动提醒，不占用前台操作。

### 3.5 PPT Master

来源：GitHub `hugohe3/ppt-master`。

PPT Master 是最值得作为 AI PPT 功能参考的开源项目。它不是套模板生成图片，而是生成真正的原生可编辑 PPTX。

值得借鉴的亮点：

- 交付原生 PowerPoint 对象模型，包括母版、原生形状、连接符、数据驱动的图表和表格。
- 支持从 PDF、DOCX、网页、图片等材料提炼重点、规划叙事，并生成可继续编辑的 PPTX。
- 生成前先确认设计规范，包括模板、画布格式、页数、风格等；用户也可以选择快速生成跳过确认。
- 内置“设计锁定”机制，要求整套 PPT 围绕一个主线结论，页面节奏、视觉和配色保持一致。
- 支持 SVG 到 DrawingML 的生成管线，最终导出可在 PowerPoint / Keynote / WPS 继续编辑。
- 支持自定义模板、套模板工作流，以及转场、动画、演讲备注和音频旁白。
- 对图表、表格、配图、许可来源都有清晰处理，避免生成无法核验的数据。
- 保持数据不出本地，不锁定平台和模型，适合作为 NovaWay 办公模式的内部能力补充。

### 3.6 WPS AI

来源：WPS 官方教程。

WPS AI 的核心经验是“任务路由”：不是让用户找一个万能 AI 按钮，而是先选择写作、演示、阅读、表格等场景，再提供材料、约束和验收标准。

值得借鉴的亮点：

- 输入至少包含任务、对象、材料、约束、验收标准五类信息，避免通用回答。
- 复杂任务先出大纲，再逐段生成和复核，而不是一次生成终稿。
- 生成后回到原文件继续编辑，保留可回退版本。
- AI 生成内容只视为待编辑初稿，需要人工核对事实、数字、格式和权限。

### 3.7 市场格局参考

来源：中国经营报 / 东方财富、易观报告相关报道。

2026 年第二季度，桌面端 AI 原生办公智能体平台月访问量突破 6000 万次，腾讯 WorkBuddy、字节 TRAE、阿里 QoderWork 已形成第一梯队。市场正在从“多家赛马”收敛为“统一办公入口”，竞争焦点从有没有 Agent 转向：

- 是否占据用户每天打开电脑后第一个进入的桌面入口。
- 是否把 AI 能力嵌入文档、表格、会议、知识库等真实工作流。
- 是否具备企业级审计、权限、连接器和 Skill 资产沉淀能力。

## 4. 可以落到 NovaWay 的设计亮点

| 竞品亮点                 | 可落地的设计                                                          |
| ------------------------ | --------------------------------------------------------------------- |
| 输入框附近有工作台切换器 | 在办公模式首页和会话输入框上方放置场景切换器，而不是藏在侧栏          |
| 通用工作台 + 垂类工作台  | 保留通用对话，同时提供文档、PPT、会议、资料库、任务、沟通六个办公场景 |
| 先确认大纲再生成         | PPT、文档和方案类任务先输出结构化大纲，用户确认后再展开               |
| 右侧产物画布             | 对话左侧、产物预览中间、任务/产物/质量右侧三栏式工作台                |
| 模板库和“做同款”         | 把常用办公任务做成模板卡，点击后填充提示词                            |
| 可编辑产物               | 办公产物解析后进入可编辑文件视图，支持版本和导出                      |
| 单页编辑                 | PPT 生成后按页重新生成、润色、手动修改，不整稿重做                    |
| 任务面板                 | 展示待办、产物、参考信息、Skill 使用和进度                            |
| 记忆与偏好               | 记录汇报对象、常用模板、风格偏好、反复修改点                          |
| 快速模式                 | 需求充分时允许跳过澄清，直接生成                                      |

## 5. 当前 NovaWay 办公模式现状

### 5.1 已有能力

NovaWay 当前已经具备一套可扩展的办公模式底座：

- 后端有六个办公智能体：`office-document`、`office-ppt`、`office-meeting`、`office-knowledge`、`office-task`、`office-communication`。
- 六个智能体对应六个办公 Skill，定义在 `packages/opencode/src/skill/index.ts`。
- 会话输入会自动注入当前办公场景的工作流、资料需求、交付产物、质量检查与记忆重点。
- 办公回复使用“`# 办公产物`”与“`# 可沉淀记忆/可进化建议`”结构化契约，前端可以识别正文和记忆建议。
- 前端已有办公产物解析、质量检查、Markdown 导出、DOCX 导出、PPTX 导出、HTML 导出。
- PPT 已有 20+ 内置模板、自定义模板、页级预览、版式校验、图表数据校验和演讲备注导出。
- 办公模式首页和会话页已有“办公场景操作台”和“PPT 模板侧栏”的雏形。

关键代码位置：

- 办公入口与产物契约：`packages/app/src/pages/home/zen-office.ts`
- 办公模式首页：`packages/app/src/pages/home.tsx`
- 办公场景操作台：`packages/app/src/pages/session/office-agent-sidebar.tsx`
- 办公场景状态：`packages/app/src/pages/session/office-agent-context.tsx`
- 场景提示词注入：`packages/app/src/components/prompt-input.tsx`
- 办公产物解析：`packages/app/src/pages/session/office-artifact.ts`
- 办公产物导出：`packages/app/src/pages/session/office-export.ts`
- 办公质量检查：`packages/app/src/pages/session/office-quality.ts`
- AI PPT 提示词：`packages/opencode/src/skill/prompt/office-ppt.md`

### 5.2 主要差距

| 差距                     | 现状                                         | 目标                                                 |
| ------------------------ | -------------------------------------------- | ---------------------------------------------------- |
| 进入成本过高             | 办公模式首页必须选择或打开一个项目目录       | 与锻造模式一致：打开项目后使用原有对话框和会话记录   |
| 场景覆盖不完整           | 首页只暴露 AI 文档和 AI PPT 两个入口         | 六个办公场景全部可作为切换器                         |
| 场景切换位置不符合预期   | 场景切换器在会话左侧栏，未直接放在对话框上方 | 在对话框上方提供横向场景切换器                       |
| 首页没有真正可用的对话框 | 首页主要是介绍卡和打开项目按钮               | 与锻造模式一致：打开项目后直接使用原有对话框         |
| PPT 缺少大纲确认         | 当前直接让模型输出页级大纲                   | 复杂 PPT 增加大纲确认阶段，允许快速跳过              |
| PPT 缺少单页编辑         | 当前主要是整份产物复制、导出和修改提示       | 增加单页重新生成、润色、模板调整                     |
| 产物预览不够直观         | 已有页级预览和模板预览，但未形成中心画布     | 形成左侧对话、中间产物画布、右侧任务与质量三栏工作台 |

## 6. 重构设计草案

### 6.1 信息架构

重构后的办公模式建议采用以下层级：

```text
办公模式首页（与锻造模式一致）
  最近项目 / 打开项目 / 新建项目
  打开项目后进入原有会话工作台
  场景切换器：AI 文档 / AI PPT / AI 会议 / AI 资料库 / AI 任务 / AI 沟通
  主对话：复用项目原有输入框、附件、模型选择和会话记录
```

办公模式首页与锻造模式保持同一套项目与会话逻辑，不新增独立聊天页面；办公差异只体现在会话输入框上方的场景切换器和提示词上下文。

### 6.2 场景切换器

在输入框上方放置一个横向 segmented control，默认选中最近使用的场景，首次进入默认 AI 文档。切换场景时同步更新：

- 当前智能体和 Skill。
- 输入框 placeholder 与快捷模板。
- 右侧“当前目标 / 需要资料 / 交付产物 / 处理流程 / 质量检查”。
- 产物文件库过滤条件。
- 提示词注入中的场景上下文。

六个场景建议：

| 场景      | 智能体                 | 主要交付                                       |
| --------- | ---------------------- | ---------------------------------------------- |
| AI 文档   | `office-document`      | 方案、报告、周报、会议纪要、PRD、商务说明      |
| AI PPT    | `office-ppt`           | 页级大纲、页面文案、图表建议、演讲备注、PPTX   |
| AI 会议   | `office-meeting`       | 会议纪要、决议、行动项、负责人、风险、会后同步 |
| AI 资料库 | `office-knowledge`     | 资料摘要、多文档对比、知识索引、FAQ            |
| AI 任务   | `office-task`          | 目标拆解、优先级、计划、风险、依赖、跟进节奏   |
| AI 沟通   | `office-communication` | 邮件、回复、通知、中英双语、语气改写           |

### 6.3 三栏式办公工作台

会话页建议从当前“单栏对话 + 场景侧栏”演进为三栏式工作台：

- 左栏：对话流，保留现有产物识别、质量提示和复制/导出操作。
- 中栏：产物画布，文档显示排版预览，PPT 显示页级预览和模板效果，会议显示行动项表，任务显示看板或计划。
- 右栏：任务监控与上下文，包括当前待办、产物文件、参考信息、Skill 使用、记忆与进化建议。

如果当前屏幕宽度不足以显示三栏，可以折叠中间画布或右栏，保留核心聊天体验。

### 6.4 AI PPT 深度体验

在现有 PPT 能力上，建议分三层补齐：

第一层：快速生成。

- 用户输入主题、受众、页数和资料后直接生成。
- 输入框下方提供 PPT 模板选择、页数选择、受众选择。
- 支持“快速模式”，跳过澄清直接生成。

第二层：大纲确认。

- 复杂任务先生成页级大纲，每页包含标题、一句话目标、版式建议。
- 用户可接受大纲，或附加反馈驳回后让模型调整。
- 接受后进入逐页生成。

第三层：页级编辑与交付。

- 左侧展示页缩略图，中间渲染当前页。
- 单页支持“重新生成”“润色文案”“更换模板”“手动修改”。
- 提供演讲备注、数据图表核验、质量检查清单。
- 支持导出 PPTX、PDF、HTML，支持保存为模板。

与 PPT Master 对齐时，可以优先补齐：

- 设计锁定：生成前确定画布、页数、受众、核心信息、风格、配色、字体密度。
- 原生可编辑导出：当前 PPTX 导出应继续保证文字、表格、图表和备注可继续编辑。
- 模板学习：允许上传 PPTX / PDF / 图片作为风格参考，自动提取颜色、布局和字体气质。
- 单页级操作：避免修改一页导致整份 PPT 重做。

## 7. 建议实施顺序

### P0：办公模式入口重构

- 把 `zenActions` 从文档、PPT 扩展到六个办公场景。
- 新建“办公工作台首页”，进入即显示特色、场景切换器和对话框。
- 支持无目录直接对话，目录绑定作为可选项。
- 把场景切换器放到输入框上方，并与右侧场景面板联动。

### P1：办公工作台完善

- 为每个场景补齐快捷模板、输入提示、交付产物和工作流。
- 在会话页增加产物画布和任务面板。
- 把现有产物解析、质量检查、复制和导出能力统一到画布。
- 为六个场景补齐产物文件库和继续修改入口。

### P2：AI PPT 增强

- 增加 PPT 大纲确认流程。
- 增加单页重新生成、润色、替换模板和手动修改。
- 支持上传参考模板并学习风格。
- 增加 PPTX / PDF / HTML 导出与保存模板。
- 完善图表数据核验、演讲备注、页面节奏检查。
