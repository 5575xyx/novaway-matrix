# NovaWay 界面个性化布局调整方案

## 一、设计思路

### 1.1 设计理念

本方案以 **"极光科技"（Aurora Tech）** 为核心设计主题，灵感来源于极光流动的自然美感与前沿科技的融合。通过流动的渐变色彩、玻璃态质感、非对称布局和精致的微交互，打造一个既具有独特视觉辨识度又保持高度可用性的现代化 AI 编程助手界面。

### 1.2 设计目标

- **差异化**：打破传统 IDE/AI 助手的刻板布局，创造令人难忘的视觉体验
- **层次感**：通过背景、中景、前景的多层设计，营造空间深度
- **呼吸感**：采用更宽松的间距系统，让界面"会呼吸"
- **一致性**：保持所有视觉元素的统一设计语言
- **可用性**：在创新的同时确保功能清晰、操作直观

### 1.3 设计关键词

极光流动 · 玻璃质感 · 非对称 · 科技光晕 · 层次深度 · 微动效

---

## 二、关键调整点

### 2.1 全局背景层增强

**现状**：当前使用简单的径向渐变（`tech-radial-light/dark`），色彩过渡较为单一。

**调整方案**：

| 调整项 | 具体方案 |
|--------|----------|
| 渐变层次 | 从单层径向渐变升级为 **3 层叠加渐变**：基础色层 + 流动色层 + 高光层 |
| 动态效果 | 添加缓慢的 CSS 动画（`@keyframes aurora-flow`），模拟极光流动，周期 15-20 秒 |
| 纹理叠加 | 在主内容区添加极微弱的网格点阵纹理（`opacity: 0.03`），增强科技感 |
| 色彩方案 | 亮色模式：青蓝（#bae6fd）→ 薄荷绿（#ccfbf1）→ 淡紫（#e9d5ff）；暗色模式：深蓝紫（#1e1b4b）→ 青蓝（#0c4a6e）→ 深绿（#064e3b） |

**预期效果**：背景不再是静态的色块，而是具有生命感的流动色彩，为整个界面奠定独特的视觉基调。

---

### 2.2 侧边栏重新设计

**现状**：64px 的垂直 rail，项目以紧凑的图标列表排列，展开面板为传统的列表布局。

**调整方案**：

| 调整项 | 具体方案 |
|--------|----------|
| Rail 宽度 | 保持 64px，但增加内部元素的呼吸空间 |
| 项目卡片 | 每个项目从纯图标改为 **圆角卡片容器**（`border-radius: 12px`），增加 4px 内边距 |
| 活跃指示 | 活跃项目增加 **左侧 4px 彩色渐变指示条**（从品牌蓝到青绿的渐变），带有微弱发光效果 |
| Hover 效果 | 项目卡片 hover 时产生 **微妙的抬升感**（`translateY(-2px)` + 阴影增强） |
| 展开面板 | 使用 **玻璃态（Glassmorphism）** 效果：`backdrop-filter: blur(20px)` + `background: rgba(255,255,255,0.7)`，与背景极光自然融合 |
| 间距系统 | 项目列表间距从 `gap-3`（12px）调整为 `gap-4`（16px），增加视觉分隔 |
| 新建按钮 | "+" 按钮改为带有渐变边框的圆形按钮，hover 时旋转 90° |

**预期效果**：侧边栏从功能性列表转变为具有设计感的项目展示画廊，每个项目都像一张精致的卡片。

---

### 2.3 顶部栏优化

**现状**：40px 高度的纯功能性导航栏，视觉存在感较弱。

**调整方案**：

| 调整项 | 具体方案 |
|--------|----------|
| 分隔线 | 底部增加 **渐变色彩分隔线**（从透明到品牌蓝再到透明），高度 1px |
| 导航按钮 | 按钮增加 `border-radius: 8px`，hover 时背景色渐变过渡 |
| 品牌标识 | "DEV" 标签改为带有微弱光晕的徽章样式，增加品牌辨识度 |
| 窗口控制 | 保持简洁，但增加 hover 时的缩放反馈（`scale(1.1)`） |
| 搜索框 | 改为圆角更大的搜索栏（`border-radius: 10px`），增加左侧搜索图标 |

**预期效果**：顶部栏从单纯的工具条升级为具有品牌气质的导航头，成为视觉层次的重要组成部分。

---

### 2.4 首页（Home）重新布局

**现状**：所有元素垂直居中对齐，布局较为传统和单调。

**调整方案**：

| 调整项 | 具体方案 |
|--------|----------|
| 整体布局 | 从垂直居中对齐改为 **非对称布局**：品牌区域偏左上方（占 60% 宽度），最近项目区域偏右下方 |
| 品牌 Logo | 放大并增加 **呼吸动画**（缓慢的缩放脉冲，周期 4 秒），增加发光滤镜效果 |
| 欢迎文案 | "构建任何东西" 使用更大的字号（`text-24-medium`）和渐变文字效果（`background-clip: text`） |
| 最近项目 | 从垂直列表改为 **横向卡片滚动** 或 **2 列网格布局**，每个项目卡片包含项目名、路径和修改时间的可视化展示 |
| 装饰元素 | 在空白区域添加 **几何装饰图形**（圆形、圆环、渐变球体），使用极低透明度（`opacity: 0.05-0.1`） |
| 服务器状态 | 从简单文字改为 **精致的状态徽章**，带有脉冲动画的指示灯 |
| 打开项目按钮 | 改为带有渐变背景的 CTA 按钮，增加阴影和 hover 放大效果 |

**预期效果**：首页从简单的欢迎页转变为具有视觉冲击力的品牌展示页，给用户留下深刻的第一印象。

---

### 2.5 会话界面优化

**现状**：传统的消息列表 + 底部固定输入框布局。

**调整方案**：

| 调整项 | 具体方案 |
|--------|----------|
| 输入框区域 | 改为 **悬浮式设计**（类似现代 AI 聊天应用），与内容区有 16px 间距，增加阴影（`shadow-lg`） |
| 输入框样式 | 更大的圆角（`border-radius: 16px`），内部增加微妙的渐变边框 |
| 消息气泡 | 用户消息使用品牌色渐变背景，AI 消息使用玻璃态背景 |
| 模型选择器 | 改为底部工具栏的图标按钮组，hover 显示工具提示 |
| 新建会话视图 | 居中的品牌展示增加动态粒子效果（使用 CSS 实现的简单粒子） |
| 打字指示器 | 三个圆点的跳动动画，带有渐变色 |

**预期效果**：会话界面更加现代和沉浸，输入区域成为视觉焦点，聊天体验更加愉悦。

---

### 2.6 色彩和主题系统

**现状**：以蓝色（#034cff）为主色调，暗色模式较为沉闷。

**调整方案**：

| 调整项 | 具体方案 |
|--------|----------|
| 主色调 | 保留蓝色（#034cff）作为主交互色 |
| 辅助渐变 | 添加 **青绿（#14b8a6）到紫蓝（#8b5cf6）** 的渐变作为辅助色，用于装饰性元素 |
| 亮色模式 | 背景增加清新的极光感，文字保持高对比度 |
| 暗色模式 | 背景增加深邃的星空感，使用深蓝紫和墨绿作为基调，文字使用柔和的白色 |
| 强调色 | 成功（绿）、警告（橙）、错误（红）保持现有语义，但增加饱和度 |
| 玻璃态 | 统一玻璃态背景色：`rgba(255,255,255,0.08)`（暗色）/ `rgba(255,255,255,0.7)`（亮色） |

---

### 2.7 间距和排版系统

**现状**：较为紧凑的间距，字体层级差异不够明显。

**调整方案**：

| 调整项 | 具体方案 |
|--------|----------|
| 全局间距 | 主要容器 padding 从 16px 增加到 20-24px |
| 组件间距 | 相关组件组之间增加 24px 间距，不相关组件之间增加 32px 间距 |
| 标题字号 | 一级标题 `text-24`，二级标题 `text-18`，三级标题 `text-14` |
| 字重差异 | 标题使用 `font-weight: 600`，正文使用 `font-weight: 400`，强调使用 `font-weight: 500` |
| 行高 | 正文行高从 130% 增加到 150%，提升可读性 |
| 圆角系统 | 小元素 8px，卡片 12px，大容器 16px，按钮 10px |

---

### 2.8 动效和微交互

**现状**：基本的过渡动画，缺乏精致的微交互。

**调整方案**：

| 调整项 | 具体方案 |
|--------|----------|
| 页面切换 | 添加淡入淡出 + 轻微上移效果（`opacity + translateY`），持续 200ms |
| 侧边栏动画 | 展开/收起使用 `cubic-bezier(0.22, 1, 0.36, 1)` 缓动，持续 300ms |
| 按钮 Hover | 背景色渐变过渡 + 轻微缩放（`scale(1.02)`）+ 阴影增强，持续 150ms |
| 卡片 Hover | 抬升效果（`translateY(-2px)`）+ 阴影扩散，持续 200ms |
| 拖拽反馈 | 被拖拽项目增加旋转（`rotate(3deg)`）和放大（`scale(1.05)`） |
| 加载状态 | 使用渐变色进度条替代纯色，增加流动感 |
| 极光背景 | 缓慢的颜色流动动画，周期 15-20 秒，使用 `linear` 缓动 |

## 四、响应式适配策略

### 4.1 断点规划

| 断点 | 布局调整 |
|------|----------|
| `>= 1280px`（xl） | 完整布局：侧边栏展开 + 非对称首页 |
| `768px - 1279px`（md-lg） | 侧边栏收起为 rail，首页改为垂直布局 |
| `< 768px`（sm以下） | 移动端布局：底部导航 + 全屏内容区 |

### 4.2 关键适配点

- **侧边栏**：小屏幕下自动收起为 rail，点击后全屏展开
- **首页项目卡片**：中屏幕改为 2 列网格，小屏幕改为单列列表
- **输入框**：移动端保持悬浮式设计，但宽度调整为全屏减去 32px 边距
- **背景效果**：移动端简化极光动画，减少性能开销

## 五、预期视觉效果

### 5.1 整体印象

打开应用后，用户首先感受到的是**流动的极光背景**，色彩在青蓝、薄荷绿和淡紫之间缓慢流动，营造出一种科技与自然融合的独特氛围。界面元素仿佛漂浮在这层流动的色彩之上，玻璃态的侧边栏和卡片与背景产生微妙的折射效果。

### 5.2 首页效果

品牌 Logo 在左上方缓慢呼吸，带有微弱的发光。"构建任何东西"的文案使用渐变色文字，在光线下闪烁。右侧的最近项目以精致的卡片网格排列，每个卡片 hover 时轻微抬升。空白处点缀着极低透明度的几何装饰，增加空间层次。

### 5.3 会话界面效果

底部的输入框像一块悬浮的玻璃面板，带有柔和的阴影和渐变边框。用户的消息气泡使用品牌蓝渐变，AI 的回复使用半透明的玻璃态背景。整个对话区域在极光背景的衬托下显得现代而沉浸。

### 5.4 暗色模式效果

切换到暗色模式后，背景变为深邃的星空感，极光色彩转为深蓝紫和墨绿，界面元素变为半透明的暗色玻璃，文字发出柔和的光芒。整体氛围从清新的科技感转变为神秘的科技感。

## 七、风险评估与应对

| 风险点 | 影响 | 应对措施 |
|--------|------|----------|
| 极光动画性能开销 | 中 | 使用 CSS 动画（GPU 加速），移动端简化效果 |
| 玻璃态效果兼容性 | 低 | 提供纯色回退方案，不支持 `backdrop-filter` 的浏览器使用半透明背景 |
| 色彩对比度不足 | 中 | 确保所有文字对比度符合 WCAG AA 标准，使用工具检测 |
| 布局变化用户不适应 | 低 | 保持核心交互逻辑不变，仅调整视觉呈现 |
| 暗色模式色彩失衡 | 中 | 单独调试暗色模式，确保极光色彩在深色背景上依然和谐 |

## 八、验收标准

- [ ] 背景极光渐变效果在所有页面正常显示
- [ ] 侧边栏项目卡片具有 hover 抬升效果和活跃指示条
- [ ] 首页采用非对称布局，项目卡片以网格展示
- [ ] 输入框区域采用悬浮式设计，带有阴影和圆角
- [ ] 所有按钮和卡片具有平滑的 hover 过渡动画
- [ ] 亮色/暗色模式切换后视觉效果一致且和谐
- [ ] 移动端布局正常，无元素溢出或错位
- [ ] 页面切换动画流畅，无卡顿
- [ ] 文字对比度符合可读性标准
